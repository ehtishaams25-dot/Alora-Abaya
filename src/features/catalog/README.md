# Catalog Feature

The `catalog` feature handles the product listing, filtering, sorting, and pagination logic for the Alora Abaya store.

## Structure

- `components/`: Contains UI components like `CatalogProductCard`, `CatalogSidebarFilters`, and `CatalogMobileFilters`.
- `hooks/`: Contains custom hooks like `useCatalogFilters` which encapsulates the complex filter state and search parameter synchronization.
- `services/`: Contains API services for fetching catalog data (placeholder for Medusa integration).
- `types/`: Contains TypeScript type definitions for the catalog state.
